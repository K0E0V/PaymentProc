# PaymentProc

Проект по реализации и сопровождению фичи 255: идемпотентный перевод средств.

## Структура проекта

- [docs/feature255/README.md](docs/feature255/README.md) — описание контуров, арбитража, инфраструктуры и процесса деплоя.
- [docs/feature255/feature255_spec.md](docs/feature255/feature255_spec.md) — подробный технический контракт и правила работы.
- [sql/oper/README.md](sql/oper/README.md) — описание боевого контура `oper`.
- [sql/feature255/README.md](sql/feature255/README.md) — описание фичевого контура `feature255` и порядок скриптов.
- [sql/test_feature255/README.md](sql/test_feature255/README.md) — описание тестового контура `test_feature255`.
- [sql/feature255](sql/feature255) — SQL-скрипты по схеме, контракту результатов, портам и процедуре перевода.
- [sql/test_feature255](sql/test_feature255) — SQL-скрипты инфраструктуры тестов, заглушек и раннеров.

## Основные контуры

- `oper` — продакшн-инфраструктура и рабочие адаптеры.
- `feature255` — изолированная редакция логики перевода.
- `test_feature255` — тестовый контур с заглушками, ассертовыми проверками и раннерами.

## Порядок развёртывания

1. Подготовить боевую инфраструктуру в `oper`.
2. Развернуть объекты `feature255` из папки [sql/feature255](sql/feature255).
3. Развернуть тестовый контур из папки [sql/test_feature255](sql/test_feature255).
4. Переключить порты на прод или тестовый адаптеры по необходимости.
5. Выполнить контрактные и unit-тесты.

См. также [docs/feature255/README.md](docs/feature255/README.md) для детализации.
