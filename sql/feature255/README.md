# Фичевый контур: `feature255`

Данный раздел содержит скрипты, которые формируют изолированную редакцию логики перевода и контракт результата.

## Что включает секция

- создание схемы `feature255`;
- справочники статусов и отображений результата;
- функции расчета статуса и сообщения;
- синонимы-порты на инфраструктуру `oper`;
- процедура `feature255.procTransferMoney`.

## Порядок выполнения

1. [01_schema.sql](01_schema.sql) — создание схемы и таблиц статусов.
2. [02_result_contract.sql](02_result_contract.sql) — функции контракта результата.
3. [03_ports.sql](03_ports.sql) — создание портов на `oper`.
4. [04_proc_transfer_money.sql](04_proc_transfer_money.sql) — основная процедура перевода.

## Ключевой принцип

Фича не должна изменять `oper` напрямую. Она работает через внешние адаптеры и порты, позволяя безопасно тестировать сценарии отказа и идемпотентности до промоушена.
