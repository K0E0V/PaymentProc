# Деплойный пакет для пустой БД

Этот каталог содержит единый SQL-пакет, который можно выполнить на пустой базе данных.

## Что делает пакет

- создает схемы `oper`, `feature255` и `test_feature255`;
- поднимает рабочую инфраструктуру `oper`;
- создает изолированную реализацию фичи `feature255`;
- поднимает тестовую инфраструктуру `test_feature255` с заглушками;
- настраивает синонимы-порты и имитирует переключение между продом и тестами.

## Порядок запуска

```sql
:r .\00_full_deploy.sql
```

или просто выполнить содержимое файла в SQL Server Management Studio / Azure Data Studio.

## Цель

Пакет позволяет быстро развернуть всю имитацию инфраструктуры на чистой БД без необходимости собирать скрипты по частям.
